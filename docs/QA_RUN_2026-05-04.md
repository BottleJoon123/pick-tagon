## 적용된 DB / Edge Function 변경

### Phase 3B — settle-matchup 경로 변경
- `supabase/functions/settle-matchup/index.ts`
  - 변경 전: `adminClient.rpc('service_settle_matchup', ...)` (service role, auth.uid() = NULL)
  - 변경 후: `anonClient.rpc('admin_set_matchup_result', ...)` (user JWT 유지 → private.is_admin() 정상 동작)
- Edge Function 배포: version 3 (`--no-verify-jwt`)

### Phase 3A-2 — archived event guard
- `admin_set_matchup_result`: archived 이벤트에서 결과 입력 시 `event_already_archived` 예외 발생
- settled 이벤트는 차단하지 않음 (KDI-류 결과 수정 필요 사례 고려)
- migration: `20260503_admin_set_matchup_archived_guard.sql`

### Hotfix 1 — admin_upsert_matchup fighter_id TEXT cast
- `fighters.id`, `matchups.red/blue_fighter_id` 모두 TEXT 컬럼인데 함수가 `::UUID` 캐스팅 → 400 오류
- UPDATE / INSERT 4곳에서 `::UUID` 제거
- migration: `20260503_fix_matchup_fighter_ids_text.sql`

### Hotfix 2 — admin_delete_event FK 순서 + 가드
- 기존: matchups 먼저 삭제 → `picks.matchup_id` FK 위반 → 409
- 수정: event_picks → picks → matchups → events 순서
- 추가: settled/archived 이벤트 삭제 차단 (`event_already_finalized`)
- 추가: win/lose/cancelled pick 있으면 삭제 차단 (`event_has_settled_picks`)
- 추가: pending pick의 bet_cost → 유저 포인트 환급
- migration: `20260503_fix_admin_delete_event_dependencies.sql`

### Hotfix 3 — service_settle_matchup archive event_date DATE cast
- 기존: `event_date::TEXT` → `'2026-04-18 00:00:00+00'` 형식 → DATE 컬럼 insert 실패
- 실패가 nested BEGIN...EXCEPTION 블록에서 롤백되어 archive_events.status가 'upcoming'으로 남음
- 수정: `event_date::DATE` (TIMESTAMPTZ → DATE 직접 캐스팅)
- migration: `20260503_fix_service_settle_matchup_archive_date_cast.sql`
- 수동 보정: UFC FN 273, 274 archive_events → 'past'로 직접 업데이트, archive_fights 재생성
